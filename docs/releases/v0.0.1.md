# wave9000 0.0.1

The first release of wave9000: a bare, modular audio workstation, and the
sibling of [splice9000](https://github.com/solacecasino/splice9000). Record
and arrange sound on tracks, mix it, export it. Every panel can be moved,
resized, added or removed, the way foobar2000 lets you rearrange its window.

**Download:** `wave9000-0.0.1-macos-universal.zip` (7.2 MB), for Apple
Silicon and Intel Macs on macOS 11 or later. Unzip it and move wave9000.app
to Applications. The first time, **right-click → Open**: the app isn't
signed with an Apple developer certificate, so macOS asks once. Install
ffmpeg (`brew install ffmpeg`) to add files other than WAV.

## What's in it

- **Tracks.** Drop sound or video files and each goes on its own track at
  the playhead, with its waveform. Move clips along and between tracks
  (below the last makes a new one), trim their edges, split them at the
  playhead (`s`), delete, undo and redo. Clips snap to the playhead and
  other clips' edges; hold Alt (Option) to drag freely.
- **Mixer.** A strip per track: fader, meter, pan, mute (`m`), solo
  (`shift+s`) and record-arm (`shift+r`), and a master strip. Faders and
  meters share one scale, so they line up; double-click a fader for 0 dB.
- **Recording.** `r` records onto the armed track from the playhead while
  the rest plays. Takes are plain WAV files beside the project.
- **Export.** WAV (16, 24-bit or float), written by wave9000 itself;
  FLAC, MP3, AAC, Ogg and Opus through ffmpeg.
- **splice9000 projects.** Drop a `.splice` file (or File → Import
  splice9000 Project…) and its sound lands on a track of its own, each clip
  where it plays in the edit. Export a WAV and drop it back into
  splice9000.
- **A layout you arrange**, menus, plain-file settings (`settings.toml`,
  `keys.toml`, `layout.toml`, applied as soon as they're saved), and your
  work kept as you go, after a restart or a crash. ⌘S saves a `.wave`
  project. All the same way splice9000 does it.
- **Adapters.** splice9000's adapter host: drop a zip to install commands,
  panels and export formats. None come with this release.

## Measured

On an Apple Silicon MacBook Air, release build:

| | |
|---|---|
| Download / app | 7.2 MB / 6.6 MB per architecture (ffmpeg not included) |
| Memory, fresh start | 56 MB |
| CPU when idle | 0.0% |
| Playing 4 tracks | about 21% of one core, nearly all of it drawing the moving playhead and meters |
| The mixer alone, 16 tracks at 48 kHz | 0.2% of one core (604× real time) |

What to know:

- Every file is decoded once into memory, which is why playing costs so
  little, but it takes about 23 MB per stereo minute at 48 kHz (46 MB at
  96 kHz). Long projects will want the next release.
- Files are decoded at the sound output's rate. Plugging in headphones that
  run at a different rate means files are read again when wave9000 next
  starts.

## Tested

- 45 unit tests, including the mixer (gain, constant-power pan, mute,
  solo, declicked cuts), exports through the real ffmpeg read back by
  ffprobe, WAV written and read back, splice9000 projects, and dragging a
  panel with real pointer input fed through egui.
- In the app on this Mac: playback of a 4-track project with live meters,
  stopping at the end, 0% CPU afterwards, opening a real splice9000
  project, and the packaged app.

**Recording hasn't been tried with a real microphone yet:** its parts are
tested, but the whole of it hasn't run. Not tested by hand: dragging with a
real mouse, clicking menu items, and the file dialogs.

## Known limits

- No MIDI, instruments, plug-in effects, automation or tempo grid. Adapters
  run as separate programs, so they can't do live effects.
- Recording latency is set by hand (`record.offset_ms` in settings.toml).
- Mac only for now (Windows and Linux build from the same code but haven't
  been run), and the app isn't notarized.
