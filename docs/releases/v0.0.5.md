# wave9000 0.0.5

A small patch: no more half-drawn frames on a Mac.

## Downloads

macOS (universal), Windows (x64 and Arm) and Linux (x64 and Arm). Install
steps are in the [README](https://github.com/solacecasino/wave9000#installing).

## Fixed

- **A frame could flash half drawn on macOS**, most likely while the
  playhead and meters move. The window drew into a screen buffer macOS could still be showing, so when frames came faster than the screen shows them, a half-drawn frame could flash up. It now takes turns between three buffers and only draws into one macOS is done with. The fix is in [core9000 0.1.3](https://github.com/solacecasino/core9000/releases/tag/v0.1.3), the 9000 series' shared core; grace9000 0.0.4 has it too.

Nothing else changed; Windows and Linux draw the same as before.
